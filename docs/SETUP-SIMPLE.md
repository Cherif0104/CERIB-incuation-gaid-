# Setup SAVANA — 2 étapes

## Étape 1 : Créer ton compte (1 min)

1. **Supabase** → **Authentication** → **Users**
2. **Add user** → **Create new user**
3. Email : `contact.cherif.pro@gmail.com`
4. Password : (choisis un mot de passe)
5. Cocher **Auto Confirm User**
6. **Create user**

## Étape 2 : Lancer tout le SQL (1 min)

1. Ouvre le fichier **`docs/RUN-ALL-MIGRATIONS-SQL-EDITOR.sql`**
2. Ctrl+A (tout sélectionner) → Ctrl+C (copier)
3. **Supabase** → **SQL Editor** → **New query**
4. Ctrl+V (coller) → **Run**

C’est tout.

**Connexion** : http://localhost:5173/login avec ton email et ton mot de passe.
